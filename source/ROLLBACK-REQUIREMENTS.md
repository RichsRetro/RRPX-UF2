# RRPXUF2 Retail Edition — non-permanent

Retail C: boot configuration is never modified. No permanent install or retail-rollback adapter is linked, and Retail transactions accept only their four owned E: session paths. Undo session files is retained for maintenance; it is not permanent-softmod rollback. Never delete unknown files or recovery evidence automatically.

ENDGAME, RRXD Lite, the separate GPL RAM patcher, FTP, EEPROM dump, hardware information and recovery remain. Settings > Auto session patches next boot controls automatic RAM patching on subsequent Pico starts; ON preserves the previous working behavior. OFF allows manual application from Session tools. Changing this option does not remove patches already running: power off fully to clear them.

Games scans E:\Games and F:\Games, preserving G: and custom scan roots. Cold boot without the Pico returns to the original retail dashboard. E: service files and optional EEPROM dumps may remain; this does not install a permanent boot path.

Full Install is a separate development tree. No Full Install or factory-reset claims apply to this edition. Hardware testing of this Retail revision, especially FTP, remains pending.

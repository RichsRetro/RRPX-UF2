## DVD to HDD now supports E:

- Choose **E:\Games** alongside any mounted F: and G: drives. If F: and G: are absent, the menu offers E:.
- If the Games folder is missing, choose **Create Games folder and copy**.
- Before copying, the tool checks space on the selected drive, including FATX allocation. If the disc will not fit, it shows the required and available space.
- The copy screen and report use **GiB** and show exact bytes, matching the dashboard's binary units.

Tested on an Xbox by Rich. Flash the UF2 to a standard RP2040 Pico using BOOTSEL.
